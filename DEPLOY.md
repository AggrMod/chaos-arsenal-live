# Chaos Arsenal Live

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/AggrMod/chaos-arsenal-live)

## Quick Deploy

1. Click the "Deploy to Netlify" button above
2. Sign in with GitHub (takes 10 seconds)
3. Get instant live URL!

Or manually deploy:
1. Visit https://app.netlify.com/drop
2. Drag and drop the repository folder
3. Get live URL instantly
